# SPR-013.1 — Quotation Approval Flow

## Goal

Allow an existing Quotation to move from `DRAFT` to `APPROVED` through an explicit business use case.

The approval represents the customer's acceptance of the commercial proposal and is the prerequisite for creating an Order.

---

## Scope

Included:

- Domain approval behavior
- Application use case
- REST endpoint
- Global exception handling integration

Not included:

- Authentication
- Authorization
- Notifications
- Audit trail
- Production creation
- Inventory reservation

---

## Business Rules

1. Only a quotation in `DRAFT` status can be approved.

2. A quotation must contain at least one item before approval.

3. Total amount must be greater than zero.

4. Approving an already approved quotation is not allowed.

5. Closed quotations cannot be approved.

6. Approval does not create an Order automatically.

7. Order creation remains a separate explicit use case.

---

## REST API

PATCH

/api/v1/quotations/{quotationId}/approve

Response:

200 OK

```json
{
  "quotationId": "...",
  "status": "APPROVED"
}
