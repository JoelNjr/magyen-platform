# SPR-027 – Mejoras de Experiencia de Usuario para Cotizaciones

## Objetivo

Mejorar la experiencia de uso del módulo Comercial sin modificar la lógica de negocio ni la arquitectura existente.

Este sprint está enfocado únicamente en hacer que el sistema sea más cómodo, intuitivo y profesional para los usuarios de Confecciones Magyen.

---

## Objetivos

- Reemplazar UUID visibles por identificadores amigables.
- Mejorar la visualización del cliente.
- Agregar mensajes de éxito.
- Agregar confirmaciones visuales.
- Mejorar tablas.
- Mejorar tarjetas.
- Mejorar estados.
- Mejorar navegación.

No se modificarán reglas de negocio.

No se modificarán endpoints.

No se modificará la arquitectura.
