# SPR-024 — Commercial Create Quotation Frontend

## Objetivo

Implementar el primer formulario completo del sistema para permitir la creación de cotizaciones desde la interfaz web.

Este sprint conecta por primera vez un formulario React con un endpoint POST existente del backend.

El objetivo NO es rediseñar la arquitectura existente, sino reutilizar completamente el trabajo realizado durante los sprints anteriores.

---

## Alcance

Este sprint implementará únicamente el flujo de creación de cotizaciones.

No incluye:

- Edición
- Eliminación
- Login
- Autorización
- Productos dinámicos
- Adjuntos
- Búsqueda de clientes

---

## Objetivos arquitectónicos

Mantener exactamente la arquitectura definida anteriormente.
